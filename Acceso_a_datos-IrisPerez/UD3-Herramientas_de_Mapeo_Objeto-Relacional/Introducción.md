## Descripcion del Resultado de Aprendizaje

**RA3:** Gestiona la persistencia de los datos identificando herramientas de mapeo objeto relacional (ORM) y desarrollando aplicaciones que las utilizan.

Este libro cubre de forma integral el uso de tecnologias ORM en Java, desde los fundamentos de JPA hasta implementaciones avanzadas con Spring Data JPA.

---

## Tecnologias Principales

|Tecnologia|Descripcion|
|---|---|
|**JPA (Jakarta Persistence API)**|Especificacion estandar de Java para mapeo objeto-relacional|
|**Hibernate**|Implementacion ORM mas popular de JPA|
|**JPQL**|Lenguaje de consultas orientado a objetos|
|**Criteria API**|API programatica para consultas dinamicas|
|**Spring Data JPA**|Abstraccion de Spring para simplificar repositorios|
|**Lombok**|Reduccion de codigo boilerplate|

---

## Contenido del Manual

### Parte 1: Fundamentos JPA

- Introduccion a ORM y JPA
    
- Configuracion de entidades
    
- Mapeo de relaciones (OneToOne, OneToMany, ManyToOne, ManyToMany)
    
- Ciclo de vida de entidades

### Parte 2: Consultas

- JPQL (Java Persistence Query Language)
    
- Criteria API para consultas dinamicas
    
- Optimizacion con FETCH JOIN

### Parte 3: Temas Avanzados

- Gestion de transacciones
    
- Hibernate como implementacion
    
- Tecnicas avanzadas (herencia, cache, auditoria)

### Parte 4: Spring Data JPA

- Repositorios y Query Methods
    
- Paginacion y ordenacion
    
- Proyecciones y DTOs

### Herramientas

- Lombok para reducir codigo repetitivo
